# 뮤트 좀 풀어주세요 서비스 기획서 (PRD)

| 항목 | 내용 |
|---|---|
| 작성일 | 2026-10-20 |
| 상태 | 1차 공개 완료, 2차 개편(토스식 화면·쉬운 믹서) 2026-10-20 |
| 근거 | 2026-10-20 기획 인터뷰(21개 결정, 맨 끝 「결정 기록」) |
| 관련 문서 | 개발 스펙 yoochangyeon/sound-system-lab#1, 작업 규칙 `CLAUDE.md` |

이 문서는 무엇을, 누구에게, 어떤 화면으로 제공하는지를 정한다. 구현 방식(모듈, 테스트)은 개발 스펙에서 정한다. 둘이 다르면 이 문서를 먼저 고치고 스펙을 맞춘다.

---

## 1. 개요

### 한 줄 정의

교회 방송실 봉사자가 디지털 믹서의 처리 기능을 브라우저에서 직접 만지고 들으며 배우는 무료 학습 사이트.

### 배경

- 교회 방송실 봉사자 대부분은 음향을 전공하지 않았다.
- 예배 중에 하울링이 나거나, 설교가 웅웅거리거나, 어떤 채널에서 소리가 안 나도 무엇을 만져야 하는지 모른다.
- 기존 자료는 이론 위주이거나 영어 매뉴얼이다.
- 실제 콘솔은 예배 시간에만 만질 수 있어서 소리를 바꿔 보며 연습할 기회가 거의 없다.

### 목표

1. 봉사자가 주일 예배에서 자주 생기는 문제를 보고 어느 구역의 어떤 노브를 만져야 하는지 안다.
2. 처리기(EQ, 컴프레서, 게이트 등)가 소리를 어떻게 바꾸는지 귀로 구분한다.
3. 실제 콘솔 앞에서 당황하지 않도록 채널·모니터·메인으로 이어지는 믹서의 기본 구조를 쉬운 믹서로 미리 익힌다.

### 서비스 원칙

| 원칙 | 뜻 |
|---|---|
| 완전 무료 | 로그인, 진도 저장, 결제를 만들지 않는다 |
| 현장 상황에서 시작 | 이론보다 "이 소리가 나면 무엇을 만지나"를 먼저 다룬다 |
| 듣고 만지며 배운다 | 설명마다 바로 만져 볼 수 있는 위젯을 붙인다 |
| 용어는 바로 풀이 | 용어가 처음 나오면 한 줄로 풀어 쓴다 |
| 글보다 그림 | 이론은 그림·컴포넌트로 먼저 보여 주고 글은 카드마다 2~3줄로 줄인다 |
| 쉽고 익숙한 화면 | 토스처럼 밝고 큰 카드 화면. 실제 기기를 재현하지 않는다 |

## 2. 대상 사용자

### 주 대상: 교회 방송실 봉사자

| 항목 | 내용 |
|---|---|
| 배경 | 음향 비전공. 주일마다 방송실에서 콘솔을 만진다 |
| 아는 것 | 페이더 올리고 내리기, 뮤트 정도 |
| 모르는 것 | 게인 스테이징, EQ 주파수, 컴프레서·게이트 파라미터, Aux 모니터 믹스, 패치 |
| 자주 겪는 문제 | 하울링, 웅웅거리는 설교 목소리, 들쭉날쭉한 보컬 크기, 소리 안 나는 채널, 모니터가 안 들린다는 요청 |
| 쓰는 기기 | 레슨은 휴대폰(이동 중, 방송실), 실습은 태블릿 가로·노트북 |
| 쓰는 콘솔 | X32 계열 또는 dLive 계열 |

### 대상이 아닌 사람

- 음향 전공자, 레코딩 엔지니어(믹싱·마스터링 심화는 다루지 않는다)
- 특정 기기의 모든 메뉴를 배우려는 사람(매뉴얼을 대신하지 않는다)

## 3. 1차 범위

1차 범위를 전부 완성한 뒤 한 번에 공개했다(2026-10-20). 같은 날 2차 개편(토스식 화면, 그림 위주 이론, 쉬운 믹서)으로 화면을 바꿨다.

### 포함

| 영역 | 내용 |
|---|---|
| 1장 기초 | 레슨 5편: 신호 흐름, dB·게인 스테이징, 주파수와 대역, 마이크 종류·지향성, 스피커·모니터 배치. 이론은 그림 컴포넌트와 O/X 퀴즈로 보여 준다 |
| 2장 처리기 | 레슨 6편 + 위젯 5종: 프리엠프, EQ 기초(필터·Q 하나씩 들어 보기), PEQ+HPF·LPF, GEQ 31밴드(하울링 데모), 컴프레서, 게이트 |
| 3장 믹서 | 믹서 둘러보기 레슨 + 실습실(쉬운 믹서 8채널) |
| 미션 | 4종: 하울링 잡기, 설교 또렷하게, 게인 맞추기, 소리 안 나는 채널 |
| 기타 | 음원 출처 페이지 |

### 4차 확장: 디지털 믹서 기본 개념 전부 (2026-10-20 결정)

X32 계열 디지털 믹서에 기본으로 들어 있는데 사이트가 다루지 않던 개념을 모두 넣는다. 실제 기종 화면은 여전히 본뜨지 않는다. 기능과 소리만 배운다.

| 영역 | 넣는 것 | 다루는 방식 |
|---|---|---|
| 이펙트 | 리버브, 딜레이, 코러스. Insert와 Send/Return(FX 리턴) 두 방식 | 엔진·위젯·쉬운 믹서 |
| 다이내믹스 | 사이드체인(키 소스·키 필터), 덕킹, 익스팬더, 디에서, 병렬 압축(Mix), 니 | 엔진·위젯·쉬운 믹서 |
| 채널 설정 | 팬, 극성 반전, 채널 딜레이, 스테레오 링크, 센드 탭 위치(EQ 앞·페이더 앞·페이더 뒤) | 엔진·쉬운 믹서 |
| 버스 | 서브그룹, 매트릭스, 버스·메인의 EQ와 컴프 | 엔진·쉬운 믹서 |
| 운용 | DCA, 뮤트 그룹, 솔로(PFL·AFL), 씬 저장·불러오기와 리콜 세이프, 오실레이터 | 엔진·쉬운 믹서 |
| 설명만 | 토크백, 오토믹스, USB 녹음, 입출력 패치(AES50·카드), 스니펫 | 레슨 카드 |

설명만 하는 항목의 이유:

- 토크백: 사용자 마이크 입력이 필요하다. 마이크 입력은 하울링 위험으로 계속 뺀다.
- 오토믹스: 말소리 마이크가 여러 개 있어야 차이가 들린다. 지금 곡에는 말소리 소스가 없다. 말소리 곡이 들어오면 구현한다.
- USB 녹음, 입출력 패치, 스니펫: 하드웨어나 기종 고유 기능이라 웹에서 만져도 배울 것이 적다.

### 제외

| 제외 항목 | 이유 |
|---|---|
| 로그인, 진도·미션 완료 저장, 결제 | 완전 무료, 가입 없는 서비스 |
| 방문 통계, 피드백 창구 | 인터뷰에서 넣지 않기로 함 |
| 마이크 입력, 사용자 음원 파일 열기 | 권한 요청과 하울링 위험. 모두 같은 음원으로 배운다 |
| 정답 바로 적용 버튼 | 단계 힌트와 해설로 대신한다 |
| 모니터 요청 처리 미션 | 1차 화면 범위에서 뺌(씬 저장/불러오기는 4차에서 넣었다) |
| 리미터 위젯 | 엔진의 안전 리미터로 충분하다(디에서·익스팬더·사이드체인은 4차에서 넣었다) |
| 실제 기종(X32·dLive) 화면 재현 | 2차 개편에서 뺌. 실제와 비슷할수록 처음 배우는 사람에게 복잡했다(2026-10-20 사용자 피드백) |
| 다국어, 다크 모드 | 한국어만, 밝은 화면 하나 |

## 6. 화면별 구성

화면 톤은 10장 디자인 가이드(토스식)를 따른다.

### S01 홈

- 레슨 카드마다 그 레슨의 핵심 키워드를 **두 개까지** 글자로만 붙인다(예: 핵심 HPF · LPF). 알약(태그) 모양은 쓰지 않는다. 원고 머리말의 `topics`(최대 2개)에서 가져온다.

```
┌──────────────────────────────┐
│ 큰 제목: 만지고 들으며 배우는     │
│          방송실 음향            │
│ [1장부터 시작하기]  (파란 큰 버튼)  │
├──────────────────────────────┤
│ 1장 음향 기초        5개 레슨 ›   │
│ ┌ 카드: 번호 · 상황 제목 · 요약 ┐  │
│ └ … ×5                      ┘  │
│ 2장 처리기 다루기 …              │
│ 3장 믹서 실습 …                  │
├──────────────────────────────┤
│ 실습실 카드: 쉬운 믹서로 미션 4개  │
└──────────────────────────────┘
```

### S02 레슨 (카드형)

```
┌──────────────────────────────┐
│ ← 2장 · 처리기     ███████░░ 5/8 │ ← 위에 붙는 진행 바
├──────────────────────────────┤
│  카드 제목 (큰 글씨)              │
│  ┌──────────────────────────┐ │
│  │ 그림·컴포넌트·위젯           │ │
│  └──────────────────────────┘ │
│  설명 2~3줄                      │
├──────────────────────────────┤
│ [이전]              [다음 ›]     │ ← 아래에 붙는 버튼
└──────────────────────────────┘
```

- 카드 하나에 개념 하나. 글은 카드마다 2~3줄 안쪽이고, 핵심은 그림·표 대신 컴포넌트로 보여 준다.
- 2장은 **개념 먼저, 실습 나중**이다. 처리기 전체 위젯을 만지기 전에, 요소 하나만 바꾸는 '하나씩 들어 보기' 카드(슬라이더 1개 + 그래프 + 재생)로 각 요소의 뜻과 소리를 익힌다(아래 표).
- 마지막 카드의 버튼은 '다음 레슨'이다. 키보드 ←·→로도 넘긴다. 주소 끝 `#3`으로 카드를 바로 연다.
- 자바스크립트가 꺼져 있으면 카드를 세로로 모두 보여 준다.

이론 컴포넌트:

| 컴포넌트 | 쓰는 곳 | 보여 주는 것 |
|---|---|---|
| 상황 카드 | 레슨 첫 카드 | 현장 문제 한 장면 |
| 신호 흐름도 | 1장 신호 흐름, 3장 | 마이크 → 프리앰프 → 처리 → 페이더 → 메인·모니터 → 스피커 |
| 신호 흐름 지도 | 1장 신호 흐름, 2장 각 레슨, 3장 버스 | 한 장짜리 지도가 레슨마다 자란다. 처음엔 마이크 → 프리엠프 → 처리 → 페이더 → 메인·모니터, 뒤로 갈수록 처리 칸, GEQ, FX 센드·리턴, Insert, 사이드체인 키, 그룹·매트릭스가 붙는다. 갈라지는 곳(●)과 나갔다 돌아오는 길, 이번 레슨에서 새로 생긴 칸을 표시한다 |
| 레벨 미터 구간 | dB·게인 | 너무 작음 / 적당(−18~−6 dBFS) / 클리핑 구간 |
| 클리핑 체험 | dB·게인 | 게인 슬라이더를 올리면 파형 꼭대기가 잘리는 그림 |
| 주파수 지도 | 주파수, PEQ | 20 Hz~20 kHz 위에 악기 대역과 "웅웅·답답·쏘는" 표현 위치 |
| 지향성 그림 | 마이크 | 무지향·카디오이드·슈퍼카디오이드 모양 |
| 무대 배치도 | 스피커·모니터 | 메인·모니터 스피커와 마이크 방향, 하울링 고리 |
| 전후 비교 | 컴프·게이트 | 처리 전후 파형 크기 막대 |
| 핵심 카드·단계 카드 | 전체 | 한 줄 요약, 번호 붙은 따라 하기 |
| O/X 퀴즈 | 레슨 끝 | 답을 누르면 바로 정답과 한 줄 해설(기록하지 않음) |
| 실전 시나리오 퀴즈 | 레슨 끝 3장 | 교회 현장 상황으로 쉬움·보통·어려움 세 문제. 아래 '실전 퀴즈' |

#### 하나씩 들어 보기 (개념 실험)

요소 하나만 움직이는 작은 위젯이다. 슬라이더 1개, 그 요소를 보여 주는 그래프, 재생, 처리 켜기/끄기만 있다.

| 레슨 | 들어 보는 요소 |
|---|---|
| 프리엠프 | 게인 |
| EQ 기초(새 레슨) | HPF, LPF, 주파수, 게인(올리기·내리기), Q(폭), 셸프 |
| 컴프레서 | 스레숄드, 레이시오, 어택 |
| 게이트 | 스레숄드, 레인지 |

#### 실전 퀴즈 (시나리오, 단계형)

레슨마다 끝에 교회 현장 상황 문제 세 개를 둔다. 목적은 정답 암기가 아니라 **무엇부터 확인할지 사고 흐름**을 잡는 것이다.

| 난이도 | 형식 |
|---|---|
| 쉬움 | 상황 한 장면 + 고르기 1단계 |
| 보통 | 상황 + 고르기 2단계(앞 단계 답이 다음 단계의 단서가 된다) |
| 어려움 · 방탈출 | 3~4단계. 단계마다 '확인할 곳' 타일을 하나씩 눌러 단서를 열고, 단서를 모두 연 뒤에 답을 고른다. 맞히면 단서가 '단서 수첩'에 쌓인다 |

- 틀린 보기를 누르면 그 보기가 왜 아닌지 바로 알려 주고 다시 고르게 한다(실수 횟수만 보여 준다).
- 다 풀면 단계별 사고 흐름(확인한 것 → 알아낸 것)과 한 줄 교훈을 보여 준다. 기록은 남기지 않는다.
- 문제는 데이터(상황, 단계, 보기, 보기별 해설, 단서)로만 추가한다. 레슨 원고의 사실과 수치를 벗어나지 않는다.

### S03 처리기 위젯 (공통 틀)

```
┌ 처리기 이름 ──────── [처리 켜짐 ◉] ┐
│ [▶ 재생]   음원 [보컬 ▾]            │
├──────────────────────────────┤
│  그래프 (응답 곡선 / 전달 곡선 / RTA) │
├──────────────────────────────┤
│  핵심 슬라이더 1~3개 (이름·값·한 줄 뜻) │
│  ▸ 더 자세히 (나머지 조작)            │
└──────────────────────────────┘
```

| 위젯 | 핵심 조작(항상 보임) | 더 자세히(접힘) |
|---|---|---|
| 프리엠프 | 게인 | — |
| PEQ+HPF·LPF | HPF·LPF 켜기·주파수, 밴드 고르기(4개 탭) → 주파수·게인 | Q(폭) |
| GEQ | 하울링 데모, 31밴드 슬라이더(가로 스크롤) | — |
| 컴프레서 | 스레숄드, 레이시오 | 니, 어택, 릴리스, 메이크업, 검출 Peak/RMS, Mix(병렬) |
| 게이트 | 스레숄드 | 레인지, 어택, 홀드, 릴리스, 모드(게이트·익스팬더) |
| 리버브(4차) | 보내는 양, 잔향 길이 | 프리딜레이, 고역 감쇠, 방 크기 |
| 딜레이(4차) | 보내는 양, 시간 | 피드백, 고역 감쇠, 박자(1/4·1/2·점8분 등으로 시간 맞추기) |
| Insert와 Send(4차) | 방식 고르기(Insert/Send), 양 | — (두 방식을 같은 소스로 번갈아 듣는다) |
| 사이드체인·덕킹(4차) | 키 소스, 스레숄드 | 레인지, 릴리스, 키 필터 |
| 디에서(4차) | 주파수, 스레숄드 | 레이시오, 키 필터 듣기 |
| 극성·딜레이(4차) | 극성 반전, 채널 딜레이 | — (같은 소리 두 채널을 섞어 콤 필터를 듣는다) |

- 노브 대신 가로 슬라이더를 쓴다. 손가락으로 끌기 쉽고 값이 바로 보인다.
- 처리 켜기/끄기 스위치로 전후를 번갈아 듣는다.
- 처음 재생하기 전에 S08 볼륨 안내가 뜬다.

### S05 쉬운 믹서

실제 기종을 본뜨지 않은 학습용 믹서 하나다. 소리 엔진과 미션은 1차 그대로 쓴다.

```
┌ [▶ 재생]  듣기: (메인|모니터1|모니터2)   [미션 ▾] ┐
├──────────────────────────────────────────┤
│ 미션 카드: 상황 · 체크리스트 · 힌트 · 해설          │
├──────────────────────────────────────────┤
│ 채널 8개 (휴대폰에서는 가로 스크롤)                 │
│ ┌리드┐┌백킹┐┌킥┐┌스네어┐┌탐┐┌오버헤드┐┌베이스┐┌기타┐│
│ │미터│ … 페이더 · 끄기(뮤트) · 메인 보내기         ││
│ └───┘                                          │
├──────────────────────────────────────────┤
│ 선택한 채널 상세 (탭)                            │
│  입력: 연결된 입력 고르기, 게인, 입력 미터           │
│  EQ: HPF·LPF, 4밴드(응답 곡선)                   │
│  컴프: 스레숄드·레이시오(+더 자세히)               │
│  모니터: 모니터1·2로 보내는 양                     │
├──────────────────────────────────────────┤
│ 모니터1 · 모니터2 · 메인: 페이더, GEQ+RTA(열기)     │
└──────────────────────────────────────────┘
```

| 항목 | 결정 |
|---|---|
| 채널 | 8개(곡 매니페스트가 정함). Devil's Words: 리드 보컬, 백킹 보컬, 킥, 스네어, 탐, 오버헤드, 베이스, 일렉 기타 |
| 입력 | 그 곡의 소스 전부(Devil's Words는 10개) + '연결 안 됨'. 채널 상세의 '입력' 탭에서 고른다 |
| 모니터 | 2개(모니터 1 보컬, 모니터 2 밴드). 채널별 보내는 양, 모니터 GEQ와 RTA |
| 게이트 | 기본 보기에서는 뺀다. 전체 보기에서 채널 상세 탭으로 연다(4차) |
| 팬, 센드 탭 | 기본 보기에서는 팬 가운데, 센드는 페이더 앞(pre) 고정. 전체 보기에서 바꾼다(4차) |
| 듣기 | 메인, 모니터 1, 모니터 2, 정답 믹스 중 고른다. 하울링은 선택과 상관없이 들린다. 솔로가 켜지면 솔로 소리를 듣는다(4차) |

#### 전체 보기 (4차)

모든 기능을 한 화면에 늘어놓으면 '쉬운' 믹서가 아니게 된다. 믹서 위에 **기본 보기 / 전체 보기** 스위치를 둔다. 기본 보기는 위 화면 그대로이고, 전체 보기에서만 아래가 나타난다. 미션은 필요한 보기를 스스로 연다.

| 자리 | 전체 보기에서 늘어나는 것 |
|---|---|
| 맨 위 | 씬(저장·불러오기·리콜 세이프), 오실레이터, 솔로 표시(PFL/AFL, 모두 해제) |
| 채널 줄 | 채널마다 솔로 버튼과 팬. 그 위에 DCA 줄과 뮤트 그룹 버튼 |
| 채널 상세 탭 | 입력(극성·딜레이·링크 추가), 게이트, EQ, 컴프(키 소스·키 필터·Mix), 센드(모니터·그룹·FX, 탭 위치), 인서트 FX |
| 출력 탭 | 모니터, 그룹, FX(리턴 페이더와 FX 설정), 매트릭스, 메인. 버스마다 EQ·컴프·GEQ |

### S06 미션 카드

- 믹서 맨 위 카드다. 미션을 고르면 문제가 있는 믹서 상태로 바뀐다.
- 조작하는 동안 실시간으로 판정하고, 체크리스트 줄마다 ✔가 켜진다.
- 힌트는 누를 때마다 하나씩 열린다. 성공하면 해설과 '다음 미션' 버튼.
- 완료 기록은 남기지 않는다.

### S08 볼륨 안내

- 페이지를 열 때마다, 그 페이지에서 처음 재생하기 전에 한 번 띄운다(저장하지 않는다).
- 엔진에는 안전 리미터가 있고, 하울링 소리 크기에도 상한이 있다.

### S09 음원 출처

- 음원마다 곡명, 만든 사람, 출처 링크, 라이선스(CC BY 3.0 등)를 표로 적는다.
- 곡 매니페스트의 출처·조건·바꾼 점을 그대로 보여 준다.


## 8. 미션 명세

| 미션 | 상황(시작 상태) | 해결 방향 | 성공 조건 | 함정(실패 처리) |
|---|---|---|---|---|
| 하울링 잡기 | 보컬 모니터(모니터 1)의 특정 대역에서 하울링이 점점 커진다 | 모니터 1 RTA로 주파수를 찾고 모니터 1 GEQ나 채널 EQ로 그 대역을 깎는다 | 그 주파수의 하울링이 멈추고, 보컬이 모니터에서 들리는 크기는 기준 이상으로 유지 | 보내는 양·모니터 페이더·채널 페이더를 내리거나, 채널을 뮤트하거나, GEQ를 통째로 내려서 소리를 줄이면 성공으로 치지 않는다 |
| 설교 또렷하게 | 설교 채널(리드 보컬 음원으로 대신)이 웅웅거리고 크기가 들쭉날쭉하다 | HPF를 켜고, 저중역을 조금 깎고, 컴프를 가볍게 건다 | HPF 주파수, 저중역 감쇠량, 컴프 레이시오·GR이 각각 지정 범위(하한과 상한) 안 | 과하게 깎거나 눌러서 범위를 벗어나면 미완료 |
| 게인 맞추기 | 몇 채널은 클리핑, 몇 채널은 너무 작다 | 페이더가 아니라 프리엠프 게인으로 맞춘다 | 해당 채널들의 입력 피크(프리엠프 입력 미터 기준)가 목표 범위 안 | 페이더만 움직이면 입력 레벨이 그대로라 미완료 |
| 소리 안 나는 채널 | 패치, 뮤트, 페이더, 메인 할당 중 몇 곳이 잘못되어 있다 | 신호 흐름을 따라가며 끊긴 곳을 찾는다 | 지정 채널의 소리가 메인까지 나온다 | 없음 |
| 보컬이 너무 건조해요(4차) | 리드 보컬에 잔향이 전혀 없다. 리버브는 FX 슬롯에 걸려 있지만 보내는 양이 0이다 | 리드 보컬의 FX 센드를 올리고 FX 리턴을 메인에 보낸다 | 리버브 센드·리턴이 지정 범위 안이고 보컬 원음(드라이)은 그대로 | 리버브를 채널 인서트로 걸어 100% 젖은 소리로 만들거나, 센드를 지나치게 올리면 미완료 |
| 찬양팀 한 번에 줄이기(4차) | 설교 전환 때 밴드 6채널을 한꺼번에 낮춰야 한다 | 밴드 채널을 DCA 하나에 묶고 DCA 페이더를 내린다 | 밴드 채널이 모두 같은 양만큼 내려가고 채널 페이더 사이의 균형은 그대로 | 채널 페이더를 하나씩 내리면 균형이 깨져 미완료 |
| 범인 채널 찾기(4차) | 메인에서 "웅—" 잡음이 나는데 어느 채널인지 모른다 | 채널을 하나씩 PFL 솔로로 듣고 잡음 채널을 찾아 HPF를 켠다 | 잡음 채널에 HPF가 켜지고 솔로가 모두 해제 | 아무 채널이나 뮤트하면 미완료 |
| 설교 순서 불러오기(4차) | 찬양이 끝나고 설교로 넘어간다. 설교 씬이 저장되어 있다 | 설교 씬을 불러오되 리드 보컬(설교자) 채널은 리콜 세이프로 지킨다 | 씬의 값이 적용되고 세이프 채널은 그대로 | 세이프 없이 불러와 보컬 설정이 덮이면 미완료 |

- 미션마다 힌트는 2~3단계다. 처음에는 방향만 알려 주고("어느 화면을 봐야 할까?"), 갈수록 구체적으로 알려 준다("모니터 1의 GEQ에서 2.5kHz 근처").
- 성공하면 "왜 이게 답인가" 해설을 보여 준다. 해설에서 판정 기준 수치의 근거도 설명한다.
- 쉬운 믹서(8채널)에서 풀 수 있어야 한다. 소리 안 나는 채널 미션의 끊긴 입력은 '연결 안 됨'으로 둔다.
- 미션은 데이터(시작 상태, 판정, 힌트, 해설)로만 추가할 수 있게 만든다.
