## Insert는 채널 하나만 손볼 때

GEQ, 컴프레서, 디에서(보컬의 "스" 소리만 줄이는 처리기)처럼 **그 채널만** 다듬는 처리기를 끼운다.

<Term name="Mix">Insert로 리버브 같은 이펙트를 끼우면, 이펙트 소리와 원음의 비율을 Mix로 정한다. 높일수록 원음이 줄어든다.</Term>

{/* 출처: https://en.wikipedia.org/wiki/Insert_(effects_processing) (인서트로 게이트·컴프·EQ를 직렬로 끼운다, 그 채널만의 리버브도 가능), https://en.wikipedia.org/wiki/Aux-send (컴프 같은 다이내믹 처리기는 보통 인서트로 건다), 확인 2026-10-20 */}

## 세 가지 이름

<Term name="Send" en="센드">채널 소리의 복사본을 버스로 보내는 양. 채널마다 따로 정한다.</Term>
<Term name="FX 버스">이펙트로 갈 소리를 모으는 버스. 모니터 버스와 같은 구조인데, 끝에 스피커 대신 이펙트가 있다.</Term>
<Term name="Return" en="리턴">이펙트를 거친 소리가 믹서로 돌아오는 자리. 자기 페이더가 있어 잔향 전체 크기를 한 번에 정한다.</Term>

{/* 출처: https://en.wikipedia.org/wiki/Aux-send (Aux 센드는 채널 소리를 다른 곳으로 보내는 출력, 이펙트를 거친 소리는 Aux 리턴 입력으로 돌아와 이펙트 루프가 된다), 확인 2026-10-20 */}

## 실제 콘솔에서는: X32 계열

<Numbers
  items={[
    { value: '8개', label: 'FX 슬롯', tone: 'blue' },
    { value: '1~4', label: '센드 · 인서트 둘 다', tone: 'green' },

센드로 쓴 FX 1\~4는 **FX 리턴**(1L\~4R)으로 돌아온다. 기본 설정에서는 <strong>Bus 13\~16</strong>이 FX 1\~4로 소리를 보낸다. GEQ도 FX 슬롯에 인서트로 건다.

{/* 출처: docs/research/console-params.md(확인 2026-10-20) X32 기본 기능 조사(4차 확장 근거): FX 슬롯 8개, 1~4는 센드·인서트, 5~8은 인서트 전용, FX 리턴 FX 1L~4R, 기본 Bus 13~16 → FX 1~4. GEQ는 FX 슬롯 인서트([B1]) */}
